# תנועה ואנימציה: המקום המרכזי

כל כללי התנועה במקום אחד: לרילים (HyperFrames ו-GSAP), ובונוס לדפי נחיתה ולאתר (CSS).
חלק מהעקרונות והערכים כאן מבוססים על הסקילים animate, animation-vocabulary ו-emil-design-eng של Emil Kowalski (רישיון MIT, github.com/emilkowalski/skills, ראו NOTICE.md), מתורגמים ומותאמים לרילים בעברית. השאר נלמד בעבודה על רילים אמיתיים.

## 1. סדר ההחלטה (לפני שכותבים שורת קוד)

1. **האם בכלל להנפיש?** ככל שרואים משהו יותר פעמים, התנועה צריכה להיות קצרה ועדינה יותר.
   - בדף: כפתור שלוחצים עליו כל הזמן מקבל תגובת לחיצה קצרה בלבד. רגע של הצלחה (נרשמת!) הוא המקום לקצת חגיגה.
   - בריל: כל אלמנט מופיע פעם אחת, אז מותר יותר. אבל לא יותר מאפקט מרכזי אחד לכל משפט.
2. **מה המטרה?** לנקוב במילה אחת: משוב (המערכת שמעה אותך), כיוון (מאיפה זה בא ולאן הולך), מצב (משהו השתנה), גישור (שלא תהיה קפיצה), הסבר (להמחיש את המילה), שמחה (רק ברגעים נדירים). **אין מילה? לא מנפישים.**
3. **מה זז:** רק `transform` (הזזה, הגדלה, סיבוב) ו-`opacity`, ולפעמים `clip-path` לחשיפה ו-`filter: blur` לגישור. לא `width`, `height`, `top` או `left`.
4. **עקומה ומשך** (סעיף 2).
5. **יציאה:** יוצאים באותה דרך שנכנסו, ומהר יותר. מה שנכנס מלמטה יוצא למטה.

## 2. עקומות ומשכים

| מצב | עקומה | CSS | GSAP |
|---|---|---|---|
| כניסה או יציאה (ברירת מחדל) | האטה בסוף, חזקה | `cubic-bezier(0.23, 1, 0.32, 1)` | `expo.out` או `power4.out` |
| תזוזה ממקום למקום על המסך | איטי, מהיר, איטי | `cubic-bezier(0.77, 0, 0.175, 1)` | `power4.inOut` |
| מגירה או חלון מלמטה | בסגנון אייפון | `cubic-bezier(0.32, 0.72, 0, 1)` | `power3.out` |
| שינוי צבע, ריחוף | רך | `ease` | `sine.inOut` |
| תנועה קבועה (פס נע, התקדמות, זום איטי ברקע) | אחיד | `linear` | `none` |

- **לא `ease-in` על כניסה** (מתחיל לאט ומעכב בדיוק את הרגע שמסתכלים עליו). `ease-in` רק ליציאה מהירה.
- העקומות המובנות של CSS חלשות. להשתמש בטבלה. עקומה חדשה לוקחים מ-easing.dev או easings.co ולא ממציאים.
- **קפיציות (spring/back):** במידה. `back.out(1.6)` עד `back.out(2.2)` לפופ של אלמנט קטן בריל. לא על טקסט שקוראים, ולא בדף על כפתור ראשי.

**משכים בדף (ממשק):** לחיצה 100 עד 160ms. תיבת מידע קטנה 125 עד 200ms. רשימה נפתחת 150 עד 250ms. חלון או מגירה 200 עד 500ms. **ממשק נשאר מתחת ל-300ms.**
**משכים בריל:** אפשר ארוך יותר כי זה הסבר ולא ממשק. מילה נכנסת 0.2 עד 0.4 שנ'. אלמנט גדול 0.3 עד 0.5. מעבר בין קטעים 0.4 (המסה). קו שמצייר את עצמו 0.6 עד 1.0. זום רקע איטי לאורך כל הקטע (1 עד 1.06).

## 3. כללים שלא מפרים

| לא | כן |
|---|---|
| אלמנט שמופיע מ-`scale(0)` | מ-`scale(0.9-0.97)` יחד עם `opacity: 0` (שום דבר בעולם לא מופיע מכלום) |
| הכול נכנס בבת אחת | הופעה בדירוג (stagger) של 30 עד 80ms בין פריטים, ולפי חשיבות |
| `transition: all` | לכתוב בדיוק מה זז |
| תנועה שנשארת אחרי שהיא סיימה את התפקיד | להוריד, או לעבור לתנועת רקע איטית מאוד |
| חלון קופץ שגדל מהאמצע | גדל מהכפתור שפתח אותו (`transform-origin`). חלון במרכז המסך פטור |
| אנימציה בלי התחשבות במי שביקשה פחות תנועה | בדף: `@media (prefers-reduced-motion: reduce)` משאיר שקיפות וצבע, מוריד תזוזה |
| אפקט ריחוף בטלפון | `@media (hover: hover) and (pointer: fine)` |

## 4. טריק הטשטוש: גישור על מעבר שלא יושב

כששני מצבים חופפים במעבר ונראים כמו שני דברים שמתחלפים, טשטוש קצר מאחד אותם לתנועה אחת.
- **בריל:** בכל חיבור בין שני טייקים: המסה של 0.35 שנ' (join.py) וטשטוש של 9px ב-0.14 שנ' לפני החיבור ו-0.22 אחריו (התבנית). נבדק על ריל של דקה.
- **בדף:** `filter: blur(2px)` ו-`opacity: .7` בזמן ההחלפה, 200ms `ease`.
- לא יותר מ-20px. טשטוש כבד מאט את הדפדפן, בעיקר בספארי.

## 5. מתכונים לדפי נחיתה ולאתר (CSS)

```css
:root {
  --ease-out: cubic-bezier(0.23, 1, 0.32, 1);
  --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);
}

/* כפתור: תגובת לחיצה, עובדת גם במגע */
.button { transition: transform 160ms var(--ease-out); touch-action: manipulation; }
.button:active { transform: scale(0.97); }

/* הופעה בכניסה לדף, בלי JavaScript */
.card { transition: opacity 300ms var(--ease-out), transform 300ms var(--ease-out); }
@starting-style { .card { opacity: 0; transform: translateY(8px); } }

/* כמה פריטים ברצף (רשימת יתרונות, שלבים) */
.item { opacity: 0; transform: translateY(8px); animation: rise 300ms var(--ease-out) forwards; }
.item:nth-child(2) { animation-delay: 50ms; }
.item:nth-child(3) { animation-delay: 100ms; }
@keyframes rise { to { opacity: 1; transform: none; } }

/* שאלות ותשובות שנפתחות: קצר, כי זה עולה בביצועים */
.answer { overflow: hidden; transition: height 200ms var(--ease-out), opacity 200ms var(--ease-out); }

/* הודעה אחרי שליחת הטופס: נכנסת מלמטה, רכה */
.toast { transition: opacity 400ms ease, transform 400ms ease; }
@starting-style { .toast { opacity: 0; transform: translateY(100%); } }

/* חשיפה בגלילה: רק בדף שיווקי, פעם אחת, לא בכל גלילה */
.reveal { clip-path: inset(0 0 100% 0); transition: clip-path 600ms var(--ease-in-out); }
.reveal.is-visible { clip-path: inset(0 0 0 0); }

/* שגיאה בשדה: רעידה קצרה */
@keyframes shake { 25% { transform: translateX(-4px); } 75% { transform: translateX(4px); } }
.field.error { animation: shake 200ms ease; }

@media (prefers-reduced-motion: reduce) {
  .card, .item, .toast, .reveal { transition: opacity 200ms ease; animation: none; opacity: 1; transform: none; clip-path: none; }
}
```

- חשיפה בגלילה מפעילים עם `IntersectionObserver`, פעם אחת (`unobserve` אחרי ההופעה). **תוכן שחשוב לקרוא לא מוסתר מראש**: אם הסקריפט לא רץ, הכול חייב להיראות.
- אנימציה בדף לא חוסמת לחיצה בזמן שהיא רצה.
- למספרים שמשתנים (מונה, שעון): `font-variant-numeric: tabular-nums`.

## 6. בריל (HyperFrames ו-GSAP): מתכונים שעובדים

| אפקט | איך | מתי מתאים |
|---|---|---|
| מילה נכנסת עם הדיבור | `fromTo` מ-`opacity:0, scale:1.2` ב-0.22 שנ' `power3.out`. מילה דקה: `y:18, blur(6px)` ב-0.3 `power2.out` | כל הכתוביות (מובנה בתבנית) |
| קו שמצייר את עצמו (line drawing) | `pathLength="1"`, `stroke-dasharray:1`, ומ-`stroke-dashoffset:1` ל-0 ב-0.95 `power1.inOut`. ראש החץ אחרי הקו | להצביע על כפתור או מילה (מובנה בתבנית) |
| כתיבה אות אחר אות (typewriter) | כל אות ב-`span`, `display` ב-`tl.set` כל 0.05 שנ'. בעברית מפצלים עם `Intl.Segmenter` כדי שניקוד יישאר עם האות | פרומפט, הודעה, חיפוש |
| פופ (pop in) | `back.out(1.8-2.2)` מ-`scale:0.3-0.6` | אייקונים, תגיות, כפתור |
| רעידה (shake) של "לא" | `x:16`, 0.05 שנ', `repeat:5, yoyo:true` | "לא עובד", טעות |
| מחיקה בקו | קו SVG על המילה, `stroke-dashoffset` | "לא צריך X" |
| מעבר בין קטעים | המסה של 0.4 שנ' בלי תזוזה. כרטיס שבא אחריו מכסה את הקודם | קטעים משלימים (מובנה בתבנית) |
| זום רקע איטי | `scale` 1 עד 1.06, `ease:"none"`, לאורך כל הקטע | כל תמונה וקטע משלים (מובנה) |
| פריסה שמשתנה בלי שרואים | מחליפים גודל או מקום מתחת לכרטיס שמכסה את המסך | ההוק הגדול (מובנה) |

- **אנימציה ראשונה לא בשנייה 0.** מתחילים 0.1 עד 0.3 שנ' אחרי.
- **אלמנטים לא יושבים על הראש** (לפחות 80px מהשיער או מכיסוי הראש), ופריטים קטנים וצבעוניים לא על בגד מודפס, שם הם נבלעים.
- ב-HyperFrames אסור `Math.random()`, `Date.now()` או `repeat: -1`. GSAP ו-CSS transform על אותו מאפיין מתנגשים: להשתמש ב-`fromTo`.

## 7. מילון: מתיאור במילים לשם האפקט

כשהמשתמשת מתארת משהו במילים, זה השם לחפש או לבקש:

| מה רואים | השם |
|---|---|
| מופיע או נעלם בהדרגה | Fade in / Fade out |
| נכנס בהחלקה מהצד | Slide in |
| גדל קצת ומופיע | Scale in |
| קופץ פנימה עם קפיצה קטנה | Pop in |
| נחשף בהדרגה כמו וילון | Reveal (clip-path או mask) |
| פריטים מופיעים אחד אחרי השני | Stagger |
| אחד נעלם ואחר מופיע באותו מקום | Crossfade |
| צורה הופכת לצורה אחרת | Morph |
| תמונה קטנה שגדלה לכרטיס | Shared element transition |
| רקע וחזית זזים במהירות שונה בגלילה | Parallax |
| אלמנטים מופיעים כשגוללים אליהם | Scroll reveal |
| התנגדות וחזרה כשמושכים מעבר לקצה | Rubber-banding |
| רעידה של "לא" | Shake / Wiggle |
| עיגול שמתפשט מנקודת הלחיצה | Ripple |
| קו שמצייר את עצמו | Line drawing |
| טקסט שמופיע אות אחר אות | Typewriter |
| מספר שעולה עד ערך | Number ticker |
| פס מנצנץ בזמן טעינה | Skeleton / Shimmer |
| ציחוק עדין למעלה ולמטה, כמו מרחף | Float |
| נשימה, גדל וקטן בעדינות | Pulse |
| טקסט שרץ בלולאה | Marquee |
| גרירה של מחיצה בין "לפני" ל"אחרי" | Before / after slider |
| תזוזה קטנה לכיוון ההפוך לפני התנועה | Anticipation |
| משהו ממשיך לזוז קצת אחרי שעצר | Follow-through |
