# רילים במו ידייך 🎬

סקיל לקלוד קוד שעורך רילים בעברית. מצלמים את עצמך מדברת בטלפון, וקלוד מחזיר ריל מוכן לאינסטגרם:

- **כתוביות שנבנות מילה אחרי מילה** עם הדיבור, בצבעים ובגופנים של המותג שלך, עם מילה מודגשת בכל משפט
- **הוק גדול:** בשניות הראשונות את על רוב המסך, הפנים במרכז
- **חיבורים בלי קפיצות** בין טייקים, וקטעים משלימים שנכנסים ויוצאים בהמסה
- **קול נקי:** רעשים וקולות בחדר בין המילים שלך יורדים
- **צלילים עדינים** (31 צלילים חופשיים), עוצמה מאוזנת לאינסטגרם
- **בדיקת איכות אוטומטית** לפני שהריל נשלח אלייך: אורך, עוצמה, קפיצות, תמונה תקועה

נבנה על ידי **מיכל אלגרבלי, במו ידייך** · [‎@michalcreates.il](https://www.instagram.com/michalcreates.il/)

## מה צריך
- [Claude Code](https://claude.com/claude-code) (במנוי של Claude)
- מחשב עם Node 22 ומעלה, ‏FFmpeg ו-Python 3. הסקיל בודק ואומר מה חסר
- כ-3GB פנויים (מודל התמלול בעברית יורד בפעם הראשונה)

## התקנה
בטרמינל:
```bash
npx skills add micdolev-ops/reels-bemo-yadayich -g -y
```
או ידנית:
```bash
git clone https://github.com/micdolev-ops/reels-bemo-yadayich.git
cp -r reels-bemo-yadayich/skills/reels-bemo-yadayich ~/.claude/skills/
```
אחר כך פותחים מחדש את Claude Code.

## הריל הראשון
1. כותבים לקלוד: **"רילים במו ידייך: בואי נגדיר את המותג שלי"**. הוא ישאל על צבעים, גופנים ולוגו.
2. שולחים את הסרטון (או נתיב לקובץ) ואת הטקסט שאמרת, וכותבים: **"ערכי לי ריל מהסרטון הזה"**.
3. מאשרים את הטקסט שיופיע על המסך, ואחר כך את הפריימים לדוגמה. רק אז הוא מרנדר.
4. הערות? כותבים לפי שנייה: "שנייה 12: הטקסט נחתך".
